# Протокол пам'яті проєкту (LLM Wiki)

> «Schema»-шар системи пам'яті. **Ти читаєш — агент пише.**
> Патерн: Andrej Karpathy, "LLM Knowledge Bases".

## Шари пам'яті
1. **Джерела (незмінні)** — ADR (`docs/architecture/`), spec/plan (`docs/features/`), PDR (`docs/product decisions/`), датасети. Рішення не переписують — амендять або замінюють новим записом.
2. **Wiki (веде агент)** — `docs/INDEX.md` (каталог), `docs/glossary.md`, снапшот Проєкту, сторінки-синтези. Компаундний шар: оновлюється з кожним рухом.
3. **Schema (правила)** — `CLAUDE.md` (тверді правила) + цей файл (операції).
4. **LOG** — `docs/LOG.md`, append-only хронологія: хребет «що і коли».

## Три операції

### INGEST — коли з'явилось нове знання
(рішення, вимір, закритий баг, знахідка досліду)
1. Прочитати й зрозуміти.
2. Визначити місце: амендмент наявного ADR / новий ADR-spec-PDR / glossary / снапшот.
3. Записати або оновити документ (за конвенцією CLAUDE.md).
4. Крос-лінк на пов'язані документи.
5. Додати рядок у `docs/INDEX.md`.
6. Додати запис у `docs/LOG.md`.

### QUERY — коли відповідаєш на питання
1. Спершу `docs/INDEX.md` — карта.
2. Відкрити лише релевантні документи (не всі підряд).
3. Відповідь із цитатами на шляхи документів.
4. Якщо виплила цінна нова істина — підшити її назад (міні-ingest).

### LINT — періодична перевірка здоров'я (≈щомісяця або перед релізом)
Шукати: суперечності між ADR; статуси-брехню («Proposed», що вже в проді); сироти (документи поза INDEX); биті крос-лінки; діри в даних.
→ Звіт + дешеві фікси одразу + запис у LOG (тип `lint`).

## Конвенції
- Нові документи — тільки в `docs/` (ADR → `architecture/ADR-NNN-*.md`, spec/plan → `features/`, PDR → `product decisions/`).
- Після створення документа — **завжди** рядок у `docs/INDEX.md`.
- Запис у LOG: `## [РРРР-ММ-ДД] <тип> | <заголовок>`, тип ∈ ingest / decision / fix / lint / finding. Тільки додавати, не переписувати.
- Не редагувати код/скрипти/базу без явного прохання (CLAUDE.md #1).
- Конфлікт із наявним ADR — назвати явно, не робити мовчки.

## Навіщо це компаундиться
Людина курує джерела й ставить питання; агент веде бухгалтерію — крос-лінки, суперечності, консистентність — те, що люди зазвичай кидають. Пам'ять стає активом, що росте з кожною взаємодією, а не чатом, що зникає.
