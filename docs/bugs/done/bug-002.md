# Description 
While navigating between words within the vese with <> words should be arranged in the order thy appear in translation, not original text, how to manage multiple occurances of the same word is TBD, I think the same way as Strong mapping works in NASB+

## Screenshots
- ../bugs/img/bug-002-1.png

## Fix

**Root cause:** `navigateToPreviousWord`/`navigateToNextWord` iterated `nasbClickableWords` which is in Macula Hebrew order, not translation order.
**Changed:** `ReaderViewModel.swift` — added `translationOrderedClickableWords` computed var that walks `VerseSegment` in translation order, matching each segment's Strong's to the Nth occurrence of that Strong's in the Macula word list (consume-in-order, handles duplicates like three לֹא in Ps 1:1). Both navigate functions and the prev/next disabled checks in `VerseBottomSheetView.swift` now use this ordered list.
**Status:** done
