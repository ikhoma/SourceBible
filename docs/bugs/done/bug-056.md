# Description

Пробіл перед комою («God-ward , that») і подвійний пробіл між словами («which  thou
hast») у читанці, Usage та аркуші входжень.

# Root cause

Коли на одному слові кілька тегів Strong's, KJV ставить між ними пробіл:
`God-ward<S>4136</S> <S>430</S>, that`. Цей пробіл — окремий текстовий вузол, і
VerseParser лишає його окремим сегментом (так і треба для RST
`сказал<S>3004</S> <i>Бог</i>`, де це єдиний пробіл між словами). Коли після нього
йде розділовий знак чи ще один пробіл — виходить зайвий.

Заміряно (сирий текст): пробіл перед розділовим знаком — KJV 1 073 вірші;
подвійний пробіл — KJV 2 605, ASV 3; RST/UBIO — 0.

# Fix

`VerseParser.droppingSpaceBeforePunctuation` у `result()`: сегмент із самих пробілів
прибирається, якщо наступний видимий текст починається з розділового знака чи
пробілу, або попередній уже закінчується пробілом. Сегменти з Strong's не
зачіпаються → `seg_ord` (ADR-041) не зсувається, базу перебудовувати не треба.
Порт у `scripts/build_word_rendering.py` (`drop_space_before_punct`) + тест.

Після фіксу (порт на всій базі): KJV 0 / 0; лишилось UBIO 10 пробілів перед знаком
і ASV 1 подвійний — вони в самому тексті джерела, не від тегів.
