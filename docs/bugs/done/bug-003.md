# Description 
The last word H3887a for which we created a mapping from extended NASB Strongs doen't highighted in the Verse text

## Screenshots
- ../bugs/bug-003-1.png

## Fix

**Root cause:** `syncSegment`, `selectedWordDisplayText`, and `translationOrderedClickableWords` all matched segment Strong's IDs using `baseStrongsNumber` only, which strips letters/suffixes but doesn't resolve NASB extended numbers (e.g. "9238" → "3887"). So H3887a (Macula base "3887") couldn't find its NASB segment "S9238" and `selectedSegment` stayed nil — no highlight.
**Changed:** `ReaderViewModel.swift` — added `resolvedMaculaBase(_:)` helper that applies `nasbExtendedOverride` after stripping. Replaced `baseStrongsNumber` with `resolvedMaculaBase` in all three segment-matching sites.
**Status:** done
