# Description

Коли одне слово перекладу несе кілька Strong's-тегів підряд, довгий тап відкриває
ОСТАННІЙ номер, а решта слів оригіналу втрачають пару. У RST НЗ «возлюбил» і «Бог»
(Ів 3:16) відкривають артикль ὁ замість ἀγαπάω / θεός, а ἀγαπάω і θεός у вкладці
«Оригінал» не клікабельні.

## Steps to Reproduce

1. Переклад RST, Ів 3:16.
2. Довгий тап по «возлюбил».
3. Вкладка «Слово».

## Expected

ἀγαπάω (G25). «Бог» → θεός (G2316).

## Actual

ὁ (G3588, артикль) для обох. Те саме в KJV Вих 34:6: «longsuffering» (אֶרֶךְ אַפַּיִם) → H639 «гнів»,
H750 не має пари.

## Notes

**Чому на слові два теги.** Одне слово перекладу = кілька слів оригіналу:
складені вирази (KJV «longsuffering» = H750+H639, «twelve» = H8147+H6240,
«armourbearer» = H5375+H3627) і грецький артикль, якого в російській немає
(RST «Бог<S>2316</S><S>3588</S>» = ὁ θεός).

**Масштаб (заміряно 2026-09-29, групи тегів підряд на одному слові):** RST 23 317
(з них НЗ 19 480), KJV 4 031, NASB 4 640, ASV 3.

**Причина.** `VerseParser.attachStrongs` присвоював `segments[index].strongs = ids`
замість додавання — кожен наступний `</S>` на тому ж текстовому вузлі перезаписував
попередній номер. `highlightedVerseText` (Usage) уже обробляв теги підряд правильно,
тож два місця застосунку розходились.

## Fix (2026-09-29)

`segments[index].strongs += ids` — номери накопичуються в порядку тексту. Далі все
працює без змін: `verseWordSegmentPairs` уже перебирає всі номери сегмента, тож кожне
слово оригіналу отримує пару; `tapWord` бере ПЕРШУ пару сегмента — головне слово
(перший тег), а не артикль (у RST він другий).

Порт у `scripts/build_word_rendering.py` (ADR-041) змінено синхронно + тест
`test_rst_article_no_longer_steals_the_word_bug055` на реальних даних Ів 3:16.
Ефект на дані «Translated as» (порт): зіставлених входжень RST +22 тис., KJV +3 тис.;
RST G25 тепер «любить»/«возлюбить», H750 KJV — «slow»/«longsuffering».

Очікуваний побічний ефект (не регресія): у RST НЗ суттєво більше клікабельних слів в
«Оригіналі»; тап по артиклю ὁ підсвічує слово, з яким він ділить сегмент («Бог»).
