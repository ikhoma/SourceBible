# Description

When opening a word from search results a second time, the large clear ("X")
button next to the search field is missing (only the inner one remains). On the
first open it is present.

## Steps to Reproduce

1. Open search, search three different words.
2. Open each word one by one.
3. On the second word-open from search, the big clear button is gone.

## Expected

The clear button is present after every word open.

## Actual

Present on first open, missing on subsequent opens (only inner clear remains).

## Screenshots

- Drive mailbox: `img/38.jpg`, `img/38.1.jpg`

## Notes

Tester's own ref: "BUG REPORT 25". iPhone 11 / iOS 26.5.
Likely a view-state / search-bar lifecycle issue on repeated navigation.

## Investigation (2026-06-26 · subagent, sonnet)

**Real bug.** `SearchView.swift` — opening a result switches to the `.bible` tab; the
system flips `.searchable`'s `isPresented` binding (`isSearchActive`, line 18) to false
on the hidden tab. On return, `committedQuery` is still set so results render, but the
system search bar (which draws the large clear "X") isn't active → outer X missing.
First open still has `isSearchActive = true`, so it's present then.

## Proposed fix

On `onAppear` (or `onChange(of: isSearchActive)`) re-assert `isSearchActive = true` when
`committedQuery` is non-empty. Confidence: high.
