# Description

Частина слів у вкладці «Оригінал» не має **жодної** глоси: порожні всі три колонки,
тож `COALESCE(gloss_display, gloss_macula, gloss)` віддає NULL і в рядку показується
тире. Для частини слів це правильно, для частини — діра.

# Масштаб (заміряно 2026-08-19)

| | |
|---|---|
| слів без жодної глоси | **3 247** (0.5% з 607 255) |
| різних `strongs_id` | **110** |
| іврит / грека | 3 090 / 157 |

Порожнеча по колонках окремо: `gloss` — 0.5%, `gloss_display` — 5.3%,
`gloss_macula` — 24.4%. Тобто ланцюжок фолбеків працює; NULL лишається тільки там,
де порожні всі три.

## Половина діри — одне слово, і там тире ПРАВИЛЬНЕ

| номер | разів | що це | `strongs.short_def` |
|---|---|---|---|
| **H853** | **1 673** (52%) | אֵת — показник прямого додатка | `[Obj.]` |
| H6440 | 508 | פָּנִים «обличчя / перед» | `face: before` |
| H3651 | 317 | כֵּן | `right` |
| H3807a | 229 | לְ — прийменник | `to` |
| H1886j | 225 | підзапис H1886 | `said` |
| H1886c | 78 | підзапис H1886 | `to` |
| G3588 | 30 | ὁ — артикль | `the/this/who` |
| H834 | 27 | אֲשֶׁר | `which` |

`lexical_class`: `om` (object marker) — 1 674, `noun` — 560, `adv` — 327, `prep` — 246.

**H853 англійською не перекладається за природою** — це службовий маркер, а не слово.
Тире для нього чесне й правильне. Те саме значною мірою для прийменників і артикля.
За ADR-016 частки ще й не клікабельні, тож користувач до них здебільшого не дістається.

## Що лишається справжньою дірою

Прибравши H853 і грецькі службові, лишається **≈1 570 вживань** на ~100 номерах, серед
яких є цілком змістовні слова: `H6440` (508) і `H3651` (317) мають визначення в
`strongs`, але глоси в `word` немає. Тут тире — втрата, а не чесність.

Окремо: `H1886j` і `H1886c` (303 разом) — підзаписи того самого `H1886`, чий базовий
рядок уже засвітився в bug-046 і bug-048 як наповнений чужими даними (Dothan). Ймовірно
та сама родина, а не самостійний випадок.

# Чому це заведено окремо

Знайдено принагідно, під час заміру якості глос. ⛔ **Не плутати з розходженням наших
глос і перекладів** — те розходження НЕ дефект (див. Notes). Тут інше: глоси немає
взагалі.

# Напрям

1. Розділити «порожньо за задумом» (H853, артиклі, прийменники) і «порожньо через діру».
   Перше можна позначити явно, щоб більше не потрапляло в такі заміри.
2. Для другої групи з'ясувати, чому `process_glosses.py` не дає значення там, де
   `strongs.short_def` існує.
3. `H1886*` дивитись разом із bug-046, не окремо.

# Notes

⛔ **Розбіжність наших глос із перекладами — НЕ баг, а редакторське рішення** (Іван,
2026-08-19). Синтезовані глоси свідомо орієнтовані на **контекстне** значення і
звірялися з BibleHub: hesed у Вих 34:6 — `covenant loyalty`, а не загальне
`lovingkindness` (ASV). Замір 2026-08-19 показав збіг із перекладами 91.2% для сирої
`word.gloss` проти 79.0% для `gloss_display` — і ці 12 пунктів є **мірою відстані між
контекстним і словниковим значенням**, тобто саме тим, за що платили редагуванням.
Не «покращувати» `gloss_display` у бік перекладів.
