# Description

With RST active, the Verse → Original view shows the original-language gloss/text
in English instead of matching the RST translation. Reporter says it happens on
any book.

## Steps to Reproduce

1. Switch translation to RST.
2. Open Gen 1:11 → Verse → Original.

## Expected

Original-tab content reflects the RST translation rather than English.

## Actual

Original text/gloss shown in EN.

## Screenshots

- Drive mailbox: `img/33.jpg`

## Notes

Tester's own ref: "BUG REPORT 20". iPhone 11 / iOS 26.5.
TRIAGE FLAG: may overlap the "lexicon/original glosses are English for MVP"
strategy — confirm whether this is the per-word gloss (by-design EN) or the verse
text itself (should follow RST). See [bug-005].

## Investigation (2026-06-26 · subagent, opus)

Mostly **by design**: the Original tab shows `word.gloss` = English Macula gloss
(`DatabaseService.loadWords` COALESCE of `gloss_display`/`gloss_macula`/`gloss`, ~219–221);
there is no RST gloss column, so English is expected for MVP. Section & morphology labels
DO localize (same `xcstrings` path as bug-005).

## Proposed fix

No code fix for the gloss (deferred to the translated-lexicon stage). Recommend
**reclassify** as by-design + add a known-design note (like the page-turn PDR) so repeat
"original is in English" reports dedup. If the reporter meant the labels, that's the
bug-005 xcstrings gap. Confidence: medium (gloss vs labels ambiguous).
