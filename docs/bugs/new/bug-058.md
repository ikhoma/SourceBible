# Description

Для слів **надпису псалма** в KJV/ASV/NASB картка слова неповна: є словникова форма й графік вживань, але немає розділів «Form in Ps …» і «Morphology». Причина — у `verse_org` вірш 1 англійських перекладів не прив'язаний до оригінального вірша-надпису.

## Steps to Reproduce

1. Відкрити Пс 42:1 у KJV («To the chief Musician, Maschil, for the sons of Korah. As the hart panteth…»).
2. Тапнути «sons».
3. Вкладка **Word → Meaning**.

## Expected

Картка як для будь-якого слова: форма בְּנֵי у Пс 42:1, транслітерація, склад, морфологія.

## Actual

Лише лема/визначення H1121 і графік «Translated in» (перевірено Іваном на пристрої). Розділів форми й морфології немає.

## Notes

### Механізм (заміряно)

- Macula (MT) нумерує надпис як **вірш 1**, текст псалма — з вірша 2. KJV/ASV/NASB (схема `eng`) вливають надпис у свій вірш 1.
- `verse_org`: `KJV PSA 42:1 → org PSA 42:2` — **лише** текст. Оригінальний 42:1 (надпис: «for director maskil of sons Korah») не зіставлено ні з чим.
- `loadOriginalWords` завантажує слова лише з зіставлених віршів → слова надпису не потрапляють у `selectedVerse.words` → тег сегмента «sons<S>1121</S>» не знаходить пари → `tapWord` падає у фолбек `loadStrongs(for: segment)` (лексикон за номером тега, без слова Macula).

### Масштаб

| Переклад | Псалмів з незіставленим надписом | Токенів Macula в цих надписах |
|---|---|---|
| KJV | 62 | 499 |
| ASV | 62 | 499 |
| NASB | 62 | 499 |
| RST | 1 | 9 |
| UBIO | 0 | 0 |

RST/UBIO (схема `rso`, надпис як окремий вірш) зіставлені правильно — дефект саме схеми `eng`.

### Що ще зачіпає

- **Вкладка «Оригінал»** для вірша 1 цих псалмів у KJV/ASV/NASB не показує слів надпису.
- **«Translated as» (ADR-041):** теги надпису не спаровуються → випадають з чипів (для H1121 у KJV ~13 вживань «sons of Korah» тощо).
- **ADR-042:** OpenBible теж кладе надпис у вірш 1 і вирівнює його з оригінальним віршем 1 — без фікса ці токени не знайдуть пари (edge case 1 там оновлено).

### Ймовірне походження

Мапінг `eng.json` (UBS) трактує надпис як «вірш 0» без відповідника в англійській схемі; ADR-028 це прийняв для панелі «Переклади» (еталон `verify_parallel_alignment.py`: RST Пс 50:1 → KJV None). На рівні слів наслідок не розглядався.

### Варіант фікса (потребує поправки до ADR-028)

У `build_versification.py` для схеми `eng`: якщо в оригінальній главі є вірш-надпис без відповідника, а переклад вливає його у вірш 1 — додати рядок `verse_org` (переклад v1 → org v1), тобто v1 ↔ {org v1, org v2} (1:N, як уже буває). Перевірити побічні ефекти:
- панель «Переклади» і еталони `verify_parallel_alignment.py` (RST-надпис тепер знайде KJV v1 — ймовірно, правильніше, але це зміна еталона);
- зворотний хоп для крос-рефів і конкордансу (дублікати віршів у списку?);
- `verify_versification_completeness.py`.
