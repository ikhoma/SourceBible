# Description

Для частотних слів розділ **Lexical** показує опис **іншої сутності** — імені, топоніма чи
біографії людини: «king» → «King's (Valley) (Gen.14.17)», «word» → «This name means word,
speaking». А для частини слів сам заголовок визначення (`short_def`) — це назва місця:
שָׂדֶה «поле» показує «Sirion».

## Steps to Reproduce

1. Відкрити будь-який вірш із מֶלֶךְ «цар» (напр., Бут 14:1, KJV «king»).
2. Тапнути «king» → **Word → Meaning**.

## Expected

Lexical: «1) king …» (BDB מֶלֶךְ).

## Actual

Lexical: «King's (Valley) (Gen.14.17)».

## Notes

### Причина (заміряно симулятором імпорту, що збігся з базою 8 859/8 859 по обох полях)

TBESH дає на один `eStrong#` кілька рядків: основне значення, «a Meaning of» (відтінки) і
рядки-імена («a Name of», «a Part of», топоніми з великої літери). `import_stepbible_lexicons`:

- `short_def` — пише лише якщо порожнє → береться з **першого** рядка групи;
- `long_def` — перезаписує щоразу → береться з **останнього** рядка групи.

Тож пара short/long приходить з **різних рядків** у 905 id, а коли останній рядок — ім'я,
long_def описує ім'я. Коли першим стоїть рядок-ім'я, ним стає й `short_def`.

### Масштаб (критерії явні)

| що | критерій | id | вживань |
|---|---|---|---|
| long_def з рядка-імені | рядок long_def — ім'я, рядок short_def — ні, Macula вживає як не-ім'я (не Np/Ng) | **25** | **11 173** |
| short_def — рядок-ім'я | рядок short_def — ім'я з покриттям глос Macula <10%, а не-ім'я-рядок групи ≥40% | 10 | 506 |
| short і long з різних рядків | будь-яка розбіжність рядків (здебільшого нешкідлива: інший «: відтінок» того ж BDB) | 905 | 81 334 |

Найчастотніші long_def з рядка-імені: H4428 king (2 523) «King's (Valley)», H1697 word (1 441)
«This name means word, speaking», H7200 see (1 299) «(Lord will) Provide», H1 father (1 210)
«The father of Gibeon…», H8033 there (834) «(Jerusalem) Is There», H1323 daughter (587)
біографія Бат-Шуа, H4325 water (581) «Water (Gate)».

short_def — рядок-ім'я: H7704 field «Sirion» (320), H1389 hill «Gibeath-(elohim)», H3526 wash
«Washer's», H2256 cord «Mahalab», H1540 reveal «Heglam», H4805 rebellion «Egypt».

### Фікс — разом із bug-057 (крок 4d `resolve_tbesh_definitions`, `scripts/tbesh_select.py`)

- Рядок групи обирається **один** для short_def і long_def.
- Якщо Macula не тегує слово як ім'я (Np/Ng) — перший рядок, що **не** є ім'ям. Ім'я =
  морфологія `N:…`, або зв'язок dStrong «a Name of» / «a Part of» (H5553G «rock» = «The Rock /
  Sela» — глоса з малої!), або глоса з великої літери / дужки / лапки. «a Spelling of» — не ім'я
  (H7704a «field»).
- Еталони в збірці: H4428.long_def не починається з «King's» і містить «king»; H1.long_def — не
  біографія; H7704.short_def ≠ «Sirion». Тести: `scripts/tests/test_tbesh_select.py`
  (H5553 — рядок-ім'я з малої літери, H4428, H7704a).

### Нейтральна зміна, яку варто знати

Для імен, що позначають кількох людей (Lamech, Bani, Abiram), long_def тепер описує **першу**
людину групи, а не останню. Жоден варіант не правильний для всіх вживань — інформація про
конкретну особу в одному long_def за визначенням неповна.
