# Observation

Scrolling to the end of these tabs leaves a noticeable empty gap below the last
item: Verse → Cross Refs, Verse → Original, Word → Meaning, Word → Usage.

## Why it matters

The trailing empty space looks unfinished and pushes the last useful row further
from the thumb. Tester wants the last item to sit as low as possible toward the
footer.

## Possible direction

Reduce the bottom content inset / trailing padding on these scroll views so the
last row settles near the footer instead of floating mid-screen.
