# Observation

The app didn't restore the last reading position on relaunch — especially after iOS
kills it from memory, the user has to navigate back manually.

## Why it matters

Quick "remind me where I was" reopen is a core reading habit; losing position on every
cold start is friction on the most-used flow.

## Possible direction

On launch, reopen to the last opened book & verse.

## Resolution

**Done** — implemented (confirmed by Ivan, 2026-07-02). App now reopens to the last
opened book and verse on relaunch.
